# Volatile Vaal Orb Calculator

A browser-based calculator for estimating the cost and probability of Volatile Vaal Orb crafting in Path of Exile.

## Features

- Searches priced unique items from poe.ninja across accessories, armour, weapons, jewels, and flasks.
- Shows item icons, base types, variants, listing counts, and current league prices.
- Supports a custom item-price override while retaining the selected item.
- Fetches Divine Orb and Volatile Vaal Orb prices for the selected league.
- Calculates average investment, a 95% confidence budget, and outcome distributions for one or more modifiers.

The application is a single static `index.html` file and uses the existing Cloudflare proxy for poe.ninja and poe.watch requests.
